# Content Research Writer

> **Purpose:** Collaborative writing for off-repo drafts; shipped site copy needs user-approved strings.

**Load only when the user attaches this skill or asks for writing/research help.** Do not load for routine code tasks.

## Portfolio site guardrails (cpdeol.com)

When the task touches **shipped site copy** (`lib/*-data.ts`, `components/**` strings, homepage sections):

- Default: **copy discipline** in `project-standards.md` — no rewrites without exact replacement text.
- **Exception:** User explicitly requests a copy audit/rewrite and names files or sections → propose changes; apply only what they approve.
- Prefer drafts in a dedicated `.md` file or off-repo folder for long-form work.

## When to use

- Off-repo blog posts, articles, newsletters, tutorials
- Research, citations, hooks, outlines, section feedback
- **Not** for drive-by edits across the live site without named scope

## Core workflow

1. Clarify topic, audience, goal, length, tone.
2. Co-create an outline (hook → sections → conclusion → research gaps).
3. Research and add citations when asked.
4. Improve hooks and review sections incrementally.
5. Final polish: flow, clarity, citations, voice check (“Does this sound like you?”).

## Output norms

- Suggest options; do not override the writer’s voice.
- Be specific in feedback (line-level edits with “why”).
- Verify sources before citing; prefer primary links.
