# Content Research Writer — reference

> **Purpose:** Templates, examples, and extended workflows for `SKILL.md` — load only when needed.

## Outline template

```markdown
# Article Outline: [Title]

## Hook
- [Opening line/story/statistic]

## Introduction
- Context, problem, what this article covers

## Main Sections
### Section 1: [Title]
- Key points, example/evidence, [research needed]

## Conclusion
- Summary, call to action

## Research To-Do
- [ ] Source for [claim]
```

## Section feedback template

```markdown
# Feedback: [Section Name]

## What Works Well
- [Strength]

## Suggestions
### Clarity / Flow / Evidence / Style
- [Issue] → [Fix]

## Specific Line Edits
Original: > [quote]
Suggested: > [revision]
Why: [explanation]
```

## Citation styles

- Inline: `Studies show X (Author, Year).`
- Numbered: `Studies show X [1].` with `## References` at end.
- Maintain a running reference list while drafting.

## Workflow variants

| Type | Flow |
|------|------|
| Blog | Outline → research → intro feedback → sections → conclusion → polish |
| Newsletter | Hook ideas → short outline → single-session draft → link/clarity pass |
| Tutorial | Steps outline → code → explanations → test steps → troubleshooting |
| Thought leadership | Angle → existing views → thesis → POV draft → evidence → conclusion |

## Hook improvement pattern

Analyze: what works, what’s weak, emotional impact. Offer 2–3 alternatives (data-driven, question, story) with one-line “why it works.”

## Full draft review checklist

- All claims sourced; citations formatted
- Transitions smooth; CTA present
- Proofread; title options if needed

## Example: section feedback (abbreviated)

**Strengths:** concrete examples, clear structure. **Improve:** swap generic claims for specific outcomes; add citation for data claims; consider reordering sections for escalating impact.
